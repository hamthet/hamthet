# GerenciadorHTML Econet — persistência DEV

Checkpoint criptografado para continuidade autônoma. O repositório hospedeiro é público; por isso nenhum código do projeto é armazenado em claro.

O manifesto identifica a baseline física, o checkpoint DEV e os chunks criptografados. A chave AES fica exclusivamente no prompt da automação ChatGPT.

A recuperação deve validar a baseline e o SHA-256 do payload antes de aplicar os patches. O estado resultante continua DEV; V4.2 permanece a última base aprovada.
